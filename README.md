## 📌 About

A set of exercises from my React studies: a ZIP code lookup (`cep`), a small store with routes (`ecommerce`), controlled forms (`form`), loading states (`loading`) and first steps with JSX (`basic`, `apptest`).

## 🧠 What I practiced

- **Components, props and state** with hooks (`useState`, `useEffect`).
- **Fetching data** from public APIs and handling loading and error states.
- **Routing** with React Router.

## 🚀 Run locally

Each folder is a separate app. You need Node.js and Yarn (or npm).

```bash
git clone https://github.com/wanderson1873/react-fundamentals.git
```

For example, the store:

```bash
cd react-fundamentals/ecommerce
yarn install
yarn start
```
